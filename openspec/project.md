# Portfolio — Максим Кочергин

## Цель
Одностраничное интерактивное портфолио Senior Full Stack AI Engineer. Сайт объясняет опыт, стек и результаты, при этом не раскрывает внутренние данные, названия систем, персональные данные кандидатов и иные материалы под NDA.

## Стек
- React + TypeScript + Vite
- Vanilla CSS с адаптивной вёрсткой и системной светлой/тёмной темой (`prefers-color-scheme`, ручной переключатель с View Transition).
- Статический сайт, готовый к деплою на Vercel
- Корень `/` отдаёт крупную кнопку визуального портфолио и полный машиночитаемый CV в том же HTML, оформленный как `cv.md`. Копии для парсеров: `/ai.html`, `/llms.txt`, `/.well-known/llms.txt`, `/ai.json`.

## Архитектура
- `public/theme.css` + `public/theme.js` — токены светлой/тёмной темы, переключатель и анимация смены палитры. Без сохранённого выбора тема следует системе.
- `src/aiDump.ts` — сборка машиночитаемого дампа из `src/data.ts` в HTML / llms.txt / JSON. HTML-копия визуально читается как markdown-файл, при этом в тексте нет `#`/`-` — префиксы только в CSS.
- Корень сайта — крупная ссылка на визуальную версию; полный CV уже в HTML корня для ИИ/парсеров. Шапка дампа на `/`: «Страница для чтения ИИ агентами и ботами. Вход для людей по кнопке выше». NDA-дисклеймер остаётся в `/ai.html`, JSON и llms.txt.
- `src/App.tsx` — секции страницы и интерактивные элементы.
- `src/styles.css` — дизайн-система и адаптивная вёрстка.
- Внешние публичные продукты открываются во встроенном `iframe`; NDA-проекты показываются как карточки без чувствительных деталей.
- Галереи кейсов: `phone` (ONEpage, Tarot Bot, CV Processing Assistant) и `wide` (Energy Metering, Reviews BI). Ассеты в `public/onepage/`, `public/tarot/`, `public/cv/`, `public/energy/`, `public/reviews/`. На скринах Energy Metering числа размыты; клиентские названия не указываются.
- Резюме: собственный PDF и HTML-превью в `public/resume/` без аутстафф-брендинга; секция Resume даёт просмотр в попапе и скачивание.
- Секция Metrics показывает проектные ориентиры «до → после»: сценарии переключаются, числа анимируются; закон Гудхарта задаёт принцип интерпретации.

## Правила
- Язык интерфейса — русский, названия технологий и общеупотребимые термины — на английском.
- Не публиковать точные внутренние URL, ключи, персональные данные, клиентские названия, бюджеты, ID, схемы БД и внутренние процессы.
- Для NDA-кейсов показывать только обезличенные домен, ценность, инженерные решения и стек.
- Поддерживать keyboard navigation, семантическую разметку и `prefers-reduced-motion`.
